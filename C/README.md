# Structure and String Integrated Program

## Problem Statement

Write a C program using structures, strings, arrays,
conditions, loops, and functions.

Define a structure named Item with:
- Item_Name
- Category
- Item_ID
- Price
- Quantity

## Tasks

1. Take input for all structure members.
2. Display the item details.
3. Replace the first letter of Category with 'X'.
4. Convert Item_Name to uppercase and separate characters with '#'.
5. Display the lengths of Item_Name and Category.
6. Concatenate Item_Name and Category into full_code.
7. Copy the first half of Item_Name.
